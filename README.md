# 🦖 T-Rex Runner

**▶ Играть: [dino-runner-black.vercel.app](https://dino-runner-black.vercel.app)**

Монохромный пиксель-арт раннер в духе оффлайн-динозаврика из Chrome, упакованный
как **Telegram Mini App**. Маленький Т-Рекс бежит по мокрому асфальту, перепрыгивает
кактусы и постепенно разгоняется. Над трассой — пиксельное солнце, плывущие облака
и сменяющаяся погода (дождь, снег, пасмурно) для полного погружения.

Первая игра из серии моих **Self Projects** — делаю для себя и для канала,
с упором на то, чтобы было качественно, душевно и залипательно.

> Интерфейс полностью на русском. Графика — два цвета: тёмный «мокрый асфальт» и белый фон.

## ✨ Что есть в v0.1.0

- 🏃 Классический бег с прыжками через кактусы, постепенное ускорение.
- 🦘 Плавный прыжок: импульс вверх + гравитация, вариативная высота (короткий тап — ниже).
- 💀 Экран **GAME OVER** с кнопками «Повторим» и «Меню», сохранение рекорда.
- ☀️ Атмосфера: пиксельное солнце, параллакс-облака, смена погоды (только визуал).
- 🔊 Синтезированные звуки (WebAudio) с тумблером в настройках.
- 📱 Интеграция с Telegram: разворот на весь экран, защита от свайпа-закрытия, haptics.
- 📜 Экран изменений (changelog) с историей версий.

## 🎮 Управление

- **Тап по экрану** / **пробел** / **↑** — прыжок.
- Короткое нажатие — низкий прыжок, удержание — выше (вариативная высота).

## 🛠 Технологии

| Слой        | Выбор                                  |
| ----------- | -------------------------------------- |
| Сборка      | [Vite](https://vitejs.dev) + TypeScript |
| Рендеринг   | HTML5 Canvas 2D (без игровых движков)  |
| UI / меню   | Нативный DOM + CSS                      |
| Telegram    | `telegram-web-app.js` (официальный SDK) |
| Хостинг     | [Vercel](https://vercel.com)           |

Бандл — около **20 КБ** (≈7.5 КБ gzip): критично для мобильного WebView.

## 🚀 Локальный запуск

```bash
npm install
npm run dev      # дев-сервер на http://localhost:5173
npm run build    # типизация + продакшн-сборка в dist/
npm run preview  # предпросмотр собранной версии
```

Игра работает и в обычном браузере, и внутри Telegram (вызовы SDK безопасны при его отсутствии).

## ☁️ Деплой на Vercel

Проект — статический сайт (output `dist`), Vercel определяет Vite автоматически.

```bash
vercel            # preview-деплой
vercel --prod     # продакшн
```

Конфиг — в [`vercel.json`](./vercel.json).

## 🤖 Подключение к Telegram-боту

1. Открой [@BotFather](https://t.me/BotFather) и выбери своего бота.
2. **Bot Settings → Menu Button → Configure Menu Button** (или команда `/newapp` для отдельного Mini App).
3. Укажи **продакшн-URL с Vercel**: `https://dino-runner-black.vercel.app`
4. Готово — кнопка меню бота открывает игру как Mini App.

> Для полноценного раскрытия на весь экран и haptics нужен актуальный клиент Telegram.

## 🗺 Архитектура и задел на рост

Код намеренно разбит на слои, чтобы расширять игру без переписывания:

```
src/
├── core/      # renderer (integer-scaling), loop, storage, audio
├── theme/     # palette.ts (биомы/гамма), skins.ts (скины)
├── game/      # Game.ts + entities (Dino, Obstacle) + systems + world (sky/ground/weather)
├── ui/        # ScreenManager + экраны (Menu, Settings, Donate, Changelog, GameOver)
├── telegram/  # обёртка над WebApp SDK
├── i18n/      # строки (готово к мультиязычности)
└── data/      # changelog
```

- **Биомы / расширение палитры** → добавить тему в `theme/palette.ts`.
- **Скины** → добавить запись в `theme/skins.ts` (спрайты — перекрашиваемые битмап-матрицы).
- **Баланс** → все константы в `src/config.ts`.
